# docs-for-beginner

## When To Use

Use this skill when writing beginner-friendly setup docs, MCP usage instructions, Godot addon notes, or validation examples.

## Rules

- Start with what to run.
- Explain why each step matters in plain language.
- Use concrete project paths and `res://` examples.
- Include a tiny example that can be checked safely.

## Limits

- Do not assume advanced Godot knowledge.
- Do not include real secrets.
- Do not make users generate assets before the base is verified.

## Result Checklist

- Commands are copyable.
- Setup and validation are separate.
- Common failure modes are named.
- Next safe step is clear.
